2. Information we collect

3. AI-assisted processing

VetScribe uses OpenAI API services for:

  • Speech-to-text transcription using GPT-4o mini Transcribe.
  • AI-assisted structuring and generation of consultation notes.

Consultation audio is temporarily processed for transcription and is not permanently stored by VetScribe.

Generated notes must be reviewed by veterinary professionals before becoming part of clinical records.
