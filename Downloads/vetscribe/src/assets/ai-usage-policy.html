VetScribe AI Usage Policy

1. Purpose

VetScribe uses artificial intelligence to assist veterinary professionals with documentation.

2. AI features

AI is used for:

  • Speech transcription.
  • Structuring consultation notes.
  • Improving documentation workflows.

3. Human review required

AI-generated outputs must always be reviewed by qualified veterinary professionals.

VetScribe does not replace veterinary judgement.

4. Audio processing

Audio recordings are temporarily processed for transcription and are not permanently stored.

5. Data handling

OpenAI API services are used for AI processing.

VetScribe has disabled sharing of API inputs and outputs for model improvement purposes.

6. Limitations

AI output may contain inaccuracies and should be verified before use.
