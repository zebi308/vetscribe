VetScribe Security Statement

Clariana AI applies security measures designed to protect veterinary practice data.

Security controls

  • HTTPS/TLS encryption.
  • Secure authentication through Supabase.
  • Database access controls.
  • Row Level Security policies.
  • Protected API credentials.
  • Secure payment processing through Stripe.
  • Logical separation of practice data.

Data infrastructure

Supabase PostgreSQL hosted on AWS infrastructure in Asia Pacific (Seoul), South Korea.

AI security

OpenAI API inputs and outputs are not shared for model improvement purposes.

VetScribe continues to improve security controls as the platform develops.
